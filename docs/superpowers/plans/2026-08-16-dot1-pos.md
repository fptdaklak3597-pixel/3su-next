# Đợt 1 POS — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline). Steps use checkbox syntax.

**Goal:** POS web + mobile bán đúng: cộng dồn, Ghi nợ, mệnh giá, beep, cảnh hết hàng.

**Architecture:** Logic giỏ/giảm/%/cảnh kho/beep nằm `sales.ts` + `posSound.ts` để test. UI chỉ gọi. `confirmSale` nhận `payMethod: 'debt'` = nợ cả đơn.

**Tech Stack:** Vite, Dexie, Zustand, Vitest, Web Audio.

## Global Constraints

- Không đụng `3su.shop` / app cũ. Identifier English, comment Vietnamese.
- `confirmSale` vẫn atomic. Giảm % → số tiền trước khi gọi.
- Beep tôn trọng `soundOn`. Overlay mừng web 1000ms.
